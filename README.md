# Financeiro SaaS

Dashboard financeiro para acompanhar uma operacao SaaS pequena. A tela concentra receita recebida, valores em aberto, faturas recentes e um resumo simples por plano.

## Recursos

- Indicadores de receita, valores em aberto e contas em atraso.
- Lista de faturas com cliente, plano, vencimento, valor e status.
- Filtro por status da fatura.
- Grafico de MRR por plano feito com CSS.
- Layout adaptado para telas menores.

## Tecnologias

- React
- TypeScript
- Vite
- CSS
- Lucide React

## Rodando localmente

```bash
npm install
npm run dev
```
